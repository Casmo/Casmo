# Glossary

Vocabulary for the Casmo GitHub profile README.

## Profile README
The README.md shown on github.com/Casmo. It has four parts, in order: Intro, Games section, Web development section, Contact footer.

## Intro
A few sentences introducing Mathieu (Casmo), in a calm professional tone without emoji.

## Games section
The animated part of the profile. It shows the games and game platforms Mathieu has built, as Game tiles. Couchfriends belongs here, not in Web development.

## Game tile
One cell in the Games section grid: a Clip, linked to where the game can be played or bought, with a one-line caption.

## Clip
A short looping animation of a game, shown inside a Game tile.

## Web development section
The professional part of the profile: a summary of Mathieu's web development work across his GitHub history, focused on technology, frameworks, open source and organisations. Repository names are not mentioned. No emoji.

## Contact footer
The closing line with ways to reach Mathieu.
